# Weather Data Analysis Using Python and Pandas

# Project Overview
This project explores a weather dataset using Python and the Pandas library. The objective is to practice data inspection, filtering, descriptive statistics, and grouping techniques to analyze weather conditions and related measurements.

## Dataset
The dataset contains 8,784 records and 8 columns, including:

Date/Time

Temperature (°C)

Dew Point Temperature (°C)

Relative Humidity (%)

Wind Speed (km/h)

Visibility (km)

Atmospheric Pressure (kPa)

Weather Conditions


## Tools and Technologies
Python

Pandas

Jupyter Notebook

CSV data processing


## Analysis Performed
Inspected dataset dimensions, columns, data types, and unique values.

Counted weather conditions and examined unique wind speeds.

Identified missing values.

Filtered records using single and multiple conditions.

Calculated mean, standard deviation, and variance.

Grouped records by weather condition.

Compared minimum, maximum, and average numeric measurements across weather conditions.


## Key Skills Demonstrated
Data exploration and inspection

Data filtering and Boolean indexing

Missing-value detection

Descriptive statistical analysis

GroupBy and aggregation

Working with CSV files in Pandas


## Project Files
1.Weather.ipynb — Jupyter Notebook containing the analysis and Python code.

2. Weather Data.csv — Dataset used in the analysis.

## Conclusion
This project demonstrates foundational exploratory data analysis techniques using Python and Pandas, with a focus on understanding weather data through filtering, descriptive statistics, and grouped analysis.
